# Sistema de Gestión Veterinaria con Lista, Cola y Pila

Proyecto desarrollado en **Java** para la **Actividad Unidad II **, basado en la implementación de estructuras de datos personalizadas mediante **nodos enlazados**.

## Descripción

La aplicación simula un sistema de atención en una **veterinaria**, donde se gestionan mascotas a través de tres estructuras de datos:

- **Lista**: almacena todas las mascotas registradas en el sistema.
- **Cola**: organiza las mascotas pendientes por orden de llegada (**FIFO**).
- **Pila**: guarda el historial de mascotas atendidas y permite deshacer la última atención (**LIFO**).

## Funcionalidades

- Registrar mascota para atención
- Ver todas las mascotas registradas
- Ver mascotas pendientes
- Procesar siguiente mascota
- Ver historial de mascotas atendidas
- Buscar mascota por código
- Cancelar mascota pendiente
- Deshacer última atención
- Ver cantidad de elementos
